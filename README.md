# 🎓 Student Grade Calculator

## 📌 Description
This is a Python-based project that calculates student grades based on marks in multiple subjects. It also provides comments, class statistics, and formatted output.

## 🚀 Features
- Input multiple student data
- Calculates average marks
- Assigns grades (A, B, C, D, F)
- Provides comments based on performance
- Displays results in table format
- Shows class statistics (average, highest, lowest)
- Input validation using loops and error handling

## 🛠️ Technologies Used
- Python 3
- Concepts:
  - Conditional Statements (if/elif/else)
  - Loops (for, while)
  - Lists & Dictionaries
  - Functions
  - Exception Handling (try-except)
